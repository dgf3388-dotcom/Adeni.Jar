# مطعم الجرة العدنيه | Al-Jarra Al-Adaniya Restaurant

موقع إلكتروني لمطعم الجرة العدنيه في حي الأثير، الدمام.

## المميزات
- قائمة طعام تفاعلية مع سلة طلبات
- إرسال الطلب مباشرة عبر واتساب
- معرض صور للأطباق
- رابط موقع المطعم على خرائط جوجل
- تصميم متجاوب (جوال + كمبيوتر)

## التشغيل المحلي
1. فك الضغط أو استنساخ المستودع
2. افتح ملف `index.html` في المتصفح

## النشر على GitHub Pages
1. ارفع الملفات إلى مستودع GitHub
2. من Settings → Pages → Source اختر الفرع `main` ومجلد `/ (root)`
3. سيظهر الموقع على: `https://YOUR_USERNAME.github.io/REPO_NAME`
